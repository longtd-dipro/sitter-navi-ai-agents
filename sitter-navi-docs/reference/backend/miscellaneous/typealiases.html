src/modules/email/email-dispatcher.interface.ts

EmailJob

Raw email job — contains EITHER a template reference OR already-rendered content.

Design: HTTP server NEVER renders EJS. It pushes raw data to the dispatcher. The dispatcher (SmtpEmailDispatcher or BullMqEmailDispatcher) handles rendering.

  • type: 'template' → dispatcher looks up template, renders EJS, sends.
  • type: 'custom' → dispatcher sends the already-provided subject/html directly.

When BullMQ is active, the Worker process handles the CPU-bound EJS rendering, keeping the HTTP server lightweight.

src/modules/push-notification/push-dispatcher.interface.ts

PushJob

Raw push job — contains EITHER a template reference OR already-rendered content.

Mirrors EmailJob pattern. The worker process handles CPU-bound EJS rendering, keeping the HTTP server lightweight.

  • type: 'template' → worker looks up template, renders EJS, gets user devices, sends.
  • type: 'custom' → worker sends the already-provided title/body directly.
