Sister Navi

Backend boilerplate xây dựng trên NestJS 11 + TypeScript 5.8, cung cấp sẵn các module phổ biến: authentication, user management, real-time chat, file storage, email, FAQ.

🚀 Quick Start (Lần đầu)

Example :
# 1. Cài dependencies
yarn install

# 2. Tạo file .env
cp .env.example .env
# Chỉnh sửa DB_URL, JWT_SECRET_KEY trong .env

# 3. Khởi động PostgreSQL + Redis
cd devops/local && docker compose up -d && cd ../..

# 4. Chạy migration
yarn migration:run-dev

# 5. Chạy dev server
yarn dev

Ứng dụng chạy tại http://localhost:3210 | Swagger UI: http://localhost:3210/swagger
